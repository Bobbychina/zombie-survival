# 丧尸末日生存 v4.0 · 余烬（大世界）

一个单机丧尸末日生存游戏：**24×24 个 1km² 区块的大世界**、宝可梦式回合制战斗、幸存者营地、方舟实验室主线与第 100 天撤离结局。

**在线试玩**：<https://bobbychina.github.io/zombie-survival/> · **许可**：PolyForm Noncommercial 1.0.0（源码可见，禁止商用，见 `LICENSE`）

构建产物 `dist/index.html` 是**一个自包含的单文件**——双击就能玩，不需要服务器、不需要联网。

```
双击 丧尸末日生存.html            → 最纯粹的"一键启动"：不需要 Node/npm，双击即玩
双击 start.bat（Windows）        → 自动装依赖 / 构建 / 起本地服务 / 开浏览器
bash start.sh（macOS / Linux）   → 同上
```

`丧尸末日生存.html` 是构建时自动从 `dist/index.html` 复制出来的单文件产物（`npm run build` 的最后一步），所以双击根目录这一份永远是最新版。两条路的唯一差别：`file://` 直开时存档写在本浏览器本地（游戏内会提示一句），本地服务则和普通网页完全一致。

## 现在能玩到什么

- **大世界（M17 起是 12×12 = 144 个区域，按种子程序化生成）**：整张元地图 144 个区域，每个区域内部是一张 24×24 个 1km² 区块的局部图（合计 144 × 576 格）；**区域类型 9 种**（城市核心 / 居民区 / 城郊 / 工业区 / 军事管制 / 农田 / 林地山区 / 废墟 / 水域港区），地图上按类型上色，一眼看出哪片是工业区、哪片是农田。**地图是"规划"出来的而不是摇号摇出来的**：分带（绕主城的圈层，边界用噪声扰动成不规则团块）→ 带内按同一张平滑噪声场切成片 → 保守元胞平滑 → 合并 <3 格的碎块，再加硬约束（**工业区不贴市中心、农田林地不进内环、军管只在山地那一角、CBD 只有一片连通**；相邻同类占比 0.6 左右，随机打散只有 0.15）。地理有"大势"：主城「余烬」永远在正中，**海岸占满一整侧、山区/军管占对角一角**，地名按"方位 + 地貌"生成（北化工 / 西粮仓 / 东码头，144 格里 100+ 个不重样）。**危险度严格按离主城的距离辐射递增**：主城 + 紧邻一圈是**安全区（新手村）**，往外铺满 1~5 档，**相邻两格最多差 1（没有任何例外，全图零断崖）**，格子里直接标数字、底边条按档位上色；想要"只看危险"就切到危险度图层。跨区沿区域图画最短路（水面只能当终点、不能当过路通道），一格 2 行动力/2 油（斜向 3/3），**一次最多开 4 格**，太远就得中途落脚。
- **区域内部地图（M15 起按"土地利用分区"生成 · M19 加"越深越难"）**：24×24 个 1km² 区块，9 种地表，迷雾探索；区块内搜刮，跨区块必须旅行。地图不是随机撒点，而是**像真实城市那样分区**：离市中心越远密度越低（`urban` 强度场 + 距离衰减）、**工业园贴着城市边缘成带**、**CBD 只有一片（带一个次级商业节点）**、居民区连片、农田/林地在最外圈、**军事管制区是一整个片区**；再跑 3 轮元胞自动机平滑 + 合并 <6 格的碎片，所以不会出现"一格工业一格农田"的插花。还有两级路网（主干道整格、市内街道只打"沿街"标记，车在公路上更快）、**每个 POI 按分区分配**（居民区出公寓/学校/超市，CBD 出写字楼/商场，工业园出物流园/建材/木材厂，稀有建筑有数量上限）、以及按分区起的地名（`铁西工业园 3 号厂区`）。**危险度是"深度"**：以安全屋为中心按距离铺满 1~5（家与紧邻一圈恒为安全区，最外两圈是一整片死地），并且**相邻格最多差 1——"越深越难"能一路走过去，不是墙**。**建筑分布也按深度偏置**：超市/药房/加油站/汽修在家附近，军械、监狱、大型商超、物流园这类硬货往深处跑——深度既是难度也是收益。
- **地图面板（M16 合并 · M17 重做大区视图 · M17.2 双图层 · M19 本地也有危险度图层）**：本地 24×24 与大区 12×12 合成**一块**，顶部一个按钮切换（`🗺️ 本地地图` / `🌐 大区地图`），当前视图会被记住——不像以前两块图上下铺开、白占一屏。两张图都带**上色图层开关**：`🎨 地貌上色`（认"这地方是什么"）/ `🔥 危险度上色`（绿→红单色梯度，认"该往哪跑"）。大区视图点一格先选中（不动身）→ 下方详情给出地名/地貌/危险度/离余烬几格/能弄到什么物资/描述，以及行程报价（`🧭 开过去 N 格 · ⚡x · ⛽y` + 途经区域）与「出发」按钮；去不了就写明原因和怎么办。选中时整条行车路线在地图上点亮，主城「余烬」有发光描边，每格里的数字就是它的危险度。
- **区域事件（M18）**：**走进一片区域、或在外过夜时，会按那片区域的地貌撞上事**——工业区可能漏毒气/管道爆燃（也可能在夜班仓库捡到成箱建材）、军管区可能撬到军械箱也可能挨巡逻无人机一梭子、农田有野猪群与粮囤、林地有狼群和伐木营地、水域会涨潮也会困住一堆鱼、废墟会塌方也可能翻出旧保险柜。出事概率随危险度上升（0.27 → 0.63），**危险区更容易抽到坏事**，而主城与紧邻一圈（安全区）**永远不会受伤**，只有氛围。出发前在区域详情里能看到"这一带的状况"，所以你能先掂量要不要去。
- **世界管理 · 种子分享（M20）**：像 MC/泰拉那样管多个世界——新建（随机种子或手填）、进入、改名、删除；每个世界有自己的地图、进度与死亡次数。**当前世界的存档仍在老位置**，所以云存档天然就是"同步当前世界"。面板里一键复制 **挑战码**（`ZS1-…` = 种子 + 开局预设：标准 / 清贫 / 地狱），发给朋友他一粘就能开一张一模一样的地图（也支持 `?challenge=` 链接）。改一位字符就会被校验和拒绝，不会"半信半疑地开局"。
- **幽灵据点 · 异步 PVP（M20）**：把自己安全屋仓库压成一段 **幽灵码**（`ZG1-…`），朋友粘进去，他的地图上就会长出一个 👻 据点（落在哪由"码 + 世界种子"决定；压在公路/水面上会自动往旁边挪一格）。踩上去打一场按威胁度缩放的守卫战（威胁 5 会带一个暴君），赢了抢走 **35% 材料（3~60）+ 一件压箱底物品**。**抢的是你分享出去的那份快照，你本人的存档一点都不少**——UI 里明说了。公共池（自动上传/拉取别人的幽灵）还没做，要先绑账号 + 明确同意。
- **开发者统计（M20，只存本机）**：死亡/结局自动记一条台账（天数、死因、区块、危险度、击杀与材料），面板直接给出"最容易吃人的是哪类地貌 / 最常见的死因 / 平均活到第几天"。**不会自动联网**——这游戏是纯静态页，没有服务器；想回传就点"导出匿名统计"（击杀与材料按 10 分桶、时间到天、无账号与存档字段），把 JSON 发给开发者即可；开发者能"合并别人的统计"多份一起看。
- **探索页 = 卡片墙（M21）**：地图独占一屏（宽屏 ≥1700px 时钉在左列），下面是 10 张卡片：**今日行动 / 格子详情 / 环境 / 采集与拆解 / 水体 / 菜园 / 今夜 / 旅途记录** + 委托板、日历（legacy 那几张也统一包成同款卡片）。一张卡只讲一件事，`auto-fill` 自动找平（1056px 宽 2 列、1440px 宽 3 列），不再有"左边一大堆、右边孤零零一张卡"。**同一个操作只有一个家**：「就地休整」只在今日行动卡、「睡觉」只在今夜卡（legacy 那颗按钮会绕过 v4 的睡眠债/环境/夜袭结算，已摘掉）。**存档与账号不占玩法版面**：顶部工具条放 `🌍 世界 · 分享` 与 `👤 账号`，面板里同时管多世界、挑战码、幽灵据点、本机统计和云存档。
- **旅行**：走路 1 行动力/区块（骨折更慢），开车 1 行动力/4 区块 + 1 油/6 区块（走公路/沿街更快）；路上会撞见东西。点亮点亮的格子先看路线与花费，再点一次才出发。**站在哪，哪一格就一定是亮的**（存档被迁移或写坏也不会让你卡在黑屏里动不了）。
- **过夜**：安全屋满额恢复、零夜袭；掩体/车里/露天过夜只恢复 65% 行动力、涨睡眠债（AP 上限 9 → 最低 6）、必掷夜袭（打断睡眠 → 丢物资 → 守夜战）。
- **血月**（每 7 天）：在家 → 守夜战（防线+陷阱全上）；不在家 → 据点被啃（门墙掉血、储物最多丢 20%）。
- **战斗**：4 招式槽、速度+先制出手顺序、7×6 属性克制、流血/中毒/燃烧/眩晕/虚弱、换武器消耗回合。**所有战斗**（含 legacy 遭遇战、守夜战、最终决战两阶段）都跑这一套引擎。
- **31 种地区（POI）**：超市/医院/警局/隧道/军事哨所/监狱/汽修厂/水厂/电台/营地/拾荒者据点/地下掩体/方舟实验室……外加水下的**沉没基地**与 7 个现代建筑（宜家家具城/五金建材城/仓储式超市/写字楼/家电城/物流园/建材市场）。**建材类建筑的每次"材料"产出额外多给 3~6 份**，木头/铁/胶带不再靠小卖部刮。
- **幸存者**：营地能交易、买情报（点亮碎片点与实验室方向）、招募同伴（继承 legacy 支线）；拾荒者据点可以交买路钱或者火并。
- **委托（接单制）**：任务页的委托板每天刷 **3 张**（挂主线的一张 + 第 3 天起一张跨区的一张 + 本地活），**要"接受"才算你的**（最多同时挂 3 张）；接了才开始算进度（接单前的进度不算，防"早就搜过所以秒完成"），有 2~5 天期限，过期作废记一次失败（不扣东西）；赏金受当日预算封顶（`20 + 2×天数`），不会变成无限材料机。每张委托都写着"谁托的"（老周/林医生/霍克…）。跨区委托要**开车过去、并在那片区域里真的搜刮 2~3 处**才算（只到访不算，判定是 `rzone:<区域>:*`）。
- **大故事（6 章 + 抉择分支）**：从余烬市区 → 一片工业区 → 港区/水域，每章有开场叙事、2~3 个目标、收束叙事，完成后写进**剧情日志**（任务页可展开回看）。章节目标按**区域类型**判定（"到访任意一处工业区"），因为世界是种子生成的、区名每次都不同。第 1/3/5 章做完目标会**停下来让你做一次抉择**（留下唯一的原件，还是交给营地？），选择决定这一章的额外奖励，并**换掉后面章节的开场叙事**——同一条主线，读到的文字不一样。章节开放要同时满足"主线阶段到位 + 目标全达成"，跨区章的提示会直接写"先弄辆车"。
- **主线**：医院线索 → 拿枪 → **3 块门禁卡碎片（钉在 3 个相隔 ≥4 区块的远点）** → 防毒面具+防化服 → 架无线电 → 方舟实验室最终决战。
- **多结局（8 个）**：结局由"**你怎么结束的**"×"**你一路上怎么选的**"共同决定——决战通关是「黎明」（抉择偏分享）还是「一个人的黎明」（偏独占）；活到第 100 天被救援是「频率上的名字」（把消息播出去过）还是「第 100 天」；死在实验室是「第六层以下」、死在荒野是「余烬」；进入无尽模式是「无尽」，在无尽里活过第 150 天变成「活得比城市久」。**结局档案**存在存档里跨周目累计，任务页可回看（未解锁的显示 🔒）。
- **撤离结局**：第 90 天无线电给出撤离坐标，带信号枪到点打信号 = 撤离（血月当天顺延）。
- **农业与季节**：四季（每 30 天）影响作物与腐坏；屋顶菜园可播种（蔬菜 5 天/麦子 9 天）、留种少收一茬、冬天户外停摆；野外**采集**（林地/农田/郊区）与**拆解**（废墟/工业区）都有每区块上限。
- **天气与体温**：8 种天气按季节加权、每天可预报明天，影响采集/作物/腐坏/生火/移动/取水；体温 0~100，低于 30 掉一档行动力与命中，**火堆和室内完全对抗**。
- **水体互动**：水边**钓鱼**（鱼竿/鱼饵/季节/天气都影响命中，每天每片水域有上限）；也能**取水**（1 行动力接 2 份污水，同一片水域每天 3 次）——污水不能直接喝，背包→制作里用**净化片**（污水1+净化片1，不用生火）或**煮沸**（污水2+木1）变成净水，净化片自己能用化工原料+布做；水块可以**游过去**（2 行动力/格，没潜水服会抽筋/感染/丢东西）；深水里有 **2 个沉没基地**，要带**氧气瓶**潜水搜（奖励是中期最肥的一档，还会遇到溺亡者）；据点可建**鱼塘**养鱼（投喂鱼饵/蔬菜翻倍，冬天减产，鱼能烤成烤鱼）。
- **伐木**：林地/废墟/农田/郊区可以**就地伐木**（1 行动力，每区块有每日上限，冬天地面冻硬产量掉到 40%）；徒手也砍得到，**撬棍 +25%、消防斧 +60%**；新增**林场**与**木材加工厂**两个 POI，家具城/五金城/建材市场/物流园也都加出木料——木料不再只能靠小卖部刮。
- **账号与云存档**：注册/登录跑在浏览器里（WebCrypto PBKDF2 加盐哈希，服务器零数据）；**可选绑定 GitHub 或微软账号**，绑定后存档同步到你自己的私有 Gist / OneDrive 应用文件夹，换设备接着玩。库在 `src/account/account.js`，同一份文件也被游戏厅页面复用。
- **存档**：进游戏**自动读取上次进度**（不用再点"继续"），读到第几天会写在日志里；想重新开始走 **菜单 → 🔄 重开新档**（有二次确认，因为会覆盖旧档——想留旧档先「⬆️ 导出」）。v1.0 老存档仍会弹迁移提示。
- 活到第 100 天还能拿到救援结局；断水断电（第 14 天）、尸群迁徙、伤口/感染/腐坏、据点建设与陷阱、支线同伴。

## 账号与云存档（可选）

不想登录也能玩：存档照样写浏览器本地。登录之后多两件事——**存档跟账号走**、**换设备接着玩**。

- 账号数据完全在本机（`localStorage`，口令用 WebCrypto PBKDF2-SHA256 加盐哈希）；**没有后端、没有数据库**。
- 绑定 **GitHub** → 存档同步到你自己账号下的**私有 Gist**（OAuth 一键 / 设备码 / 令牌粘贴三条路，免费无额度限制）。**微软那条暂不提供**：它要求在 Azure 注册应用，而个人微软账号走注册流程会被要求绑信用卡（代码与 OneDrive 逻辑仍在，填上 client_id 即可启用）。
- 不想绑任何账号也能搬存档：账号面板里的 **💾 导出存档文件 / 📂 从文件导入**（下载一个 json，另一台电脑选文件导入）。
- client_id 的注册步骤写在主页仓库的 `games/auth-config.js` 顶部（GitHub 约 3 分钟，填进去就生效）。
- **安全边界**：这是"防同事手滑"级别的本地账号——持有浏览器 profile 的人可以直接读到存档与云令牌，别拿它当密码保险箱。

### 想自己部一套云后端？（可选，免费、不用信用卡）

云账号后端就是 `tools/cf-worker.js` 一个文件（零依赖），跑在 Cloudflare Workers 免费版上：

```powershell
cd tools
npx wrangler login      # 浏览器点一次 Allow
npx wrangler deploy     # 绑定/开关都写在 wrangler.toml 里，不用点面板
```

- 唯一依赖是 wrangler 本身（用 `npx` 跑，不需要装进 `package.json`）和一次交互式登录；`wrangler.toml` 里的 `account_id` / KV namespace id 都是**标识符不是凭据**，公开无风险。
- 部署前要先有 KV 命名空间（`npx wrangler kv namespace create DSH_KV`，把返回的 id 填进 `wrangler.toml` 的 `[[kv_namespaces]]`）。
- 两个 Secret 用 `npx wrangler secret put DSH_PEPPER` / `GH_CLIENT_SECRET` 写（或在面板 Variables and secrets 里加），`keep_vars = true` 保证它们不会被后续部署抹掉。
- 部署完打开 `https://<你的>.workers.dev/api/health`，期望 `{"ok":true,"kv":true,"pepper":"custom"}`。

### 安全模型（M8.1 加固后）

| 面 | 做法 |
|---|---|
| 口令 | 浏览器 PBKDF2-SHA256 210k 派生 → 只上传 `verifier`；服务端存 `SHA256(pepper+verifier)`，pepper 是 Worker Secret（不在库里） |
| 忘了口令 | 注册时发一串**恢复码**（一次性显示）：它把存档密钥另包一份存服务端，找回时用它解开密钥再换口令，**云存档不会丢**。代价：服务端存了包裹后的密钥 → 拿到 KV 的人可离线猜口令（PBKDF2 210k + 长口令是唯一缓冲，已写进 PRIVACY.md） |
| 存档内容 | 上传前 **AES-GCM-256 端到端加密**（密钥是注册时生成的随机 DEK，口令只负责包住它；每文件随机 IV；密文带版本头）；密钥只在 `sessionStorage`，重开页面需「解锁」，退出登录即抹掉 |
| GitHub 令牌 | **不进前端**：Worker 里换 token、AES-GCM 加密后存 KV；读写 Gist 全部走 Worker 代理，且只允许动它自己创建的那一个 Gist 里的 `<game>__<slot>.json`；解绑时调 GitHub 撤销接口 |
| 冲突 | 上传带乐观锁（`expectUpdatedAt` / `expectVersion`），过期写入返回 409，客户端先拉再重试 |
| 频率 | **每账号每天 10 次上传**（UTC+8 零点重置，`429 quota_exceeded`；面板显示剩余次数）+ 自动同步两段节流（8s 合并 + 距上次写云 ≥60s）；KV 免费额度 1000 写/天 |
| 跨域 | Worker 只回显白名单 Origin（不是 `*`）+ `Vary: Origin`；游戏厅页面加了 CSP（`connect-src` 只放行自己的 Worker 与 api.github.com） |
| 暴力破解 | `/api/login`、`/api/register`、`/api/salt` 按 IP 限流 20 次/分钟 |

已知边界（诚实版）：CSP 的 `script-src` 仍需要 `'unsafe-inline'`（单文件产物把脚本内联了），所以 XSS 防线主要靠"高价值令牌不在页面里"；KV/Gist 都存在服务端可见的**元数据**（文件名、大小、更新时间）——内容本身是密文。

### 存档完整性（反作弊"取证"，不是"阻止"）

单机游戏跑在玩家机器上，**纯前端不可能阻止改档**（代码、存档、运行时全在他手里）。这里做的是三层"看得见"：

1. **指纹**：每次写档把内容的校验和写进存档自己身上（`__integrity.d`，双通道 FNV-1a），并链式带上一次的指纹；
2. **启动取证**：在 legacy `sanitizeSave` **之前**读原始 JSON——合法存档永远是被 sanitize 夹过的，所以一旦发现 `hp > hpMax`、`mat` 为负这类越界值，就说明有人在 sanitize 之外动过手（这是最有用的信号）；
3. **只给"游戏自己写的档"盖章**：在 `localStorage.setItem` 上挂钩，只有内容与内存状态一致时才重新盖指纹；用 devtools 直接往键里塞的东西**不会被盖章**，于是它的指纹永远对不上，下次启动就是证据。

发现被改过会：日志 + 弹窗提示、账号面板显示「⚠️ 存档被外部修改过」、**本档成就/排行不计入**（游戏照常能玩）。拉云端存档 / 从文件导入时先验指纹，对不上要你确认才会覆盖本机。

**边界（必须在同一条里说清）**：会写代码的人可以重算指纹，所以这套拦不住蓄意造假，它拦的是"顺手改一下"和"存档写坏了"。真要不可伪造，得让中继（Cloudflare Worker）用只有它知道的密钥做 HMAC 签名——已经有中继了，需要就能加。

### 想要"一键授权"？（可选，免费、不用信用卡，约 5 分钟）

GitHub 的换 token 接口 `login/oauth/access_token` 不给浏览器跨域头，纯静态站拿不到响应——所以默认走"令牌绑定"（2 次点击）。要真正的"一键"，部署一个中继即可（只转发、不存任何东西、不需要 client secret）：

```bash
npx wrangler login                                                   # 浏览器授权（Cloudflare 账号邮箱注册即可）
npx wrangler deploy tools/oauth-relay-worker.js --name dsh-oauth-relay
# 把输出的 https://dsh-oauth-relay.<你的子域>.workers.dev 填进
# 主页仓库 games/auth-config.js 的 github.relay
```

客户端三种情况都处理好了：**配了中继** → 中继优先、直连兜底；**没配** → 先试 form 简单请求（不触发预检）、再试 JSON；两条都失败才报错，并把每次尝试的原因写进错误里。失败面板里还有 **🔍 诊断连接**（空跑四种请求、不产生任何令牌），点一下就知道被哪一层挡住。

> 提醒：`*.workers.dev` 在部分地区会被拦。部署完先在浏览器直接打开那个地址试试能不能通。
