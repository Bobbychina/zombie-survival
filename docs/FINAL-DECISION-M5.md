## 二、正式修订项（R1~R5 / S1，全部落 `src/v4/` 常量）

- **R1 过夜参数**：安全屋满额全清（AP 回满、睡眠债 −2 档、零夜袭）；野外过夜恢复 AP 上限的 **60%~70%**，睡眠债只还半档（即净 +0.5 档/夜）。两项劣势必须同时成立（韩铮红线）。
- **R2 夜袭分档**：野睡必掷夜袭。点位分档：教堂/营地 = 低档，车里 = 中档且耗 1 燃料，掩体/监狱/军事哨所 = 高档（更安全）。后果三档递进：**打断睡眠（AP 再打折）→ 丢物资（材料/背包物品）→ 守夜战（强制战斗）**，只有安全屋零夜袭。
- **R3 结算方式**：即时掷骰 + 结果立刻落盘 + `lastResolvedNight` 幂等标记（放弃"种子重放"方案，避免读档刷新）。
- **R4 C10 不得减配**：必须保留 tap 等价路径与"点目标 → 画路线 → 报价 → 确认"；格子命中区 ≥24px。
- **R5 顶栏预算**：地图面板顶部常驻信息位 ≤3 个；睡眠债并入 AP 显示（如 `AP 8/8 · 债 1 档`），不新开一个常驻位。
- **R6 标记规范**：任何新标记进可折叠图例，且有不依赖 emoji 小字的可读文本标签。
- **S1 敏感度矩阵（合入门槛）**：野睡恢复 60/65/70% × 债偿还 0.5/1 档 × 夜袭三档 → 用脚本实测三个指标：①连续野睡第 7 天不得触底（AP 上限 ≥6）②单人 3 天远征可完成（≥3 区块/天净推进）③安全屋过夜相对野睡的净收益差距 ≥2 AP。未过矩阵不得合入 PR2。
- **C03 数值上界**：单次储物损失 ≤20%；门/墙总伤 ≤ 防线耐久 35%。
- **C07 与血月撞车规则（确定性）**：撤离窗口自第 90 天开启；若窗口开启当天是血月，窗口顺延到血月后的第一天（HUD 明写"血月顺延"）；在撤离点过夜按"掩体"档结算。不做窗口内血月照常（避免终局被随机血月撕掉）。
- **写入禁令（林渡）**：任何机制不得在玩家无操作时改变其位置；远征失败的后果是死亡/被抢/状态损失，不是位移回安全屋。

## 四、主 agent 补记：评审后读码发现的缺口（PR0）

读完 legacy 源码后确认：legacy 有**自己的一套战斗**（`startCombat` → `openCombatModal` → `drawCombat`），且三处**内部调用**不走 `window.startCombat`：

- `nightRaid()`（第 1059 行）夜间守夜战/血月战
- `encounterRoll()`（第 1947 行）区域遭遇战
- `startFinalBattle()`（第 2731 / 2739 行）最终决战两个阶段

也就是说：用户要求的"战斗改成宝可梦式回合制"目前只覆盖了 v4 自己发起的战斗，**守夜战、区域遭遇、最终决战仍在跑旧界面**。本轮 PR0 必须先修掉这个"两套战斗并存"的问题，否则 C03（复用 nightRaid）与 C07（撤离点守夜）都没有意义。
做法（桥接，不新增 legacy 功能）：legacy `startCombat` 首行检测 `window.__v4StartCombat` 并转交；v4 侧把 legacy 的 `opts.onWin/onLose/onFlee` 回调接回去（否则守夜战奖励、Boss 二阶段切换会断），并在 `siege` 场合把防线（门/墙）显示进战斗界面。
