## P1 · 内容与深度

### 1. 建筑内部地图（用户提过的想法）
- **目标**：医院/警局/超市这类 POI 进去不是"点一下搜刮"，而是一张 3~6 格的小平面图：房间有独立战利品、
  有锁门（需要撬棍/钥匙）、有埋伏；同一栋楼可以分两次搜完。
- **规模**：L（数据结构 + 渲染 + 存档 + 探针）。**风险**：和现有"格子 → POI 搜索次数"模型要接好，
  不能出现"建筑内还能再触发大世界地图"的错乱。
- **验收**：单测（平面图生成 + 门/钥匙判定 + 进度存档往返）+ 探针（进楼 → 搜两间 → 被埋伏 → 撤出）+ 截图。

### 2. 区域事件卡（QoL 清单第 14 项）
- **现状**：`region-events-core.ts` 已经有事件数据，但只在日志里出现一句。
- **目标**：进入新大区时弹一张"这里正在发生什么"的卡（2~3 个选择：绕路 / 硬闯 / 埋伏），带即时结算。
- **验收**：单测（事件池不重复、两选一的分支结果）+ 探针（跨区 → 卡片出现 → 点选 → 结算入账）。

### 3. 批处理制作（QoL 清单第 3 项）
- **目标**：制作页支持"一次做 N 个"（材料够就连做，带二次确认），并显示"做完会剩多少材料"。
- **验收**：纯函数 `craftPlan(recipe, stock, n)` 单测（上限受材料与 AP 约束、不会做过头）+ 探针点一次做完 5 个绷带。

### 4. 富余层与储物自动化（QoL 清单第 10 项）
- **目标**：储物箱按"同类自动折叠"（同物品多叠显示总数），背包里给"富余材料一键送箱"。
- **验收**：单测（折叠不丢件、送回后重量与格数正确）+ 探针。
