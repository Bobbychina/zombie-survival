# 《丧尸末日生存》v4.0 下一轮迭代草案（M5）—— 供团队审核

现状（已验收）：24×24 个 1km² 区块大世界 + 迷雾 + 走路/开车旅行 + 23 种 POI 搜刮 + 宝可梦式回合制战斗 + 营地 NPC（交易/情报/招募）+ 拾荒者据点 + 三块门禁卡碎片逼你横穿大世界 + 方舟实验室在 10~14 区块外。
技术底座：Vite + TS 多文件，新系统全在 `src/v4/`，legacy 单文件版当底座（只通过 `bridge.ts` 读写存档）；构建产物是双击可玩的单文件 `dist/index.html`；存档 `VER=2` 不变。

目标画像（用户原话）："类似僵尸毁灭工程 / MC 惊变一百天那种的丧尸末日"——要有"出门要算账、天黑前回不回得来、七天后拿什么挡血月"的压迫感，并且**通关必须横穿大世界**。

---

## 一、草案条款

### 生存循环（让大地图真的走得远）
- **C01 野外过夜**：目前只有安全屋能睡觉翻日，等于每天必须回家——10 区块外的实验室根本走不到。改为：车里 / 营地 / 教堂 / 掩体等 `feat` 允许的点位可以过夜，恢复 AP 但只恢复一部分，且夜间有被摸上门的判定。
- **C02 睡眠债**：连续不睡或野睡，AP 上限与命中率递减（上限 9 → 最低 6）；睡够恢复。给"硬撑赶路"一个真实代价。
- **C03 血月回防**：血月当天若人不在安全屋，尸群啃防线（门/墙掉血、储物间丢东西）；人在家则进入守夜战（复用 legacy `nightRaid`）。把"每 7 天"变成必须回家的强节拍。

### 世界内容密度（让每一步都有事）
- **C04 路上事件表**：区块移动时除遭遇外再掷一次事件：军用空投、路障、车祸残骸、尸群迁徙预警、幸存者求助。给材料/情报/风险，让"赶路"不再只是扣 AP。
- **C05 路上幸存者遭遇**：小概率遇到拾荒者团伙拦路：交钱 / 火并 / 绕路（多花 1AP）。与营地声望联动。
- **C06 营地声望**：每个营地一份 rep：帮忙 +、抢劫/火并 −。rep 高 → 货架更全更便宜、招募更便宜；rep 低 → 拒绝交易甚至埋伏你。

### 通关与终局
- **C07 100 天撤离点**：第 90 天无线电收到撤离坐标（地图远端 POI，独立于实验室主线）。带信号枪到撤离点 = 救援结局。给"活到第 100 天"一个必须出门的终点，而不是在家挂机。
- **C08 载具改装**：车加"油箱/装甲/轮胎"槽位，汽修厂用材料升级；车况归零会抛锚（当前只是不能开）。让"找交通工具"有长线投入。

### 体验与工程
- **C09 POI 分层（浅层）**：只对少数大 POI（医院/监狱/实验室）做 2~3 层"往里走一层"的深度机制，越深越肥越危险；小 POI 保持现状。
- **C10 地图可用性**：格子放大 + 悬停详情（名字/距离/POI/剩余次数）；点目标先画路线并报价再确认；图例可折叠。
- **C11 存档与性能**：世界对象缓存、迷雾重放只在读档时做一次（现在每次 render 重放 576 格）。
- **C12 情报指向性**：花材料买"最近的某类 POI 坐标"（找医院/警局/汽修厂/加油站），解决"关键 POI 找不到"的挫败。

## 二、不做清单（本轮明确不做）
- **X01** 不做多存档槽 / 云存档。
- **X02** 不做联机。
- **X03** 不重写 legacy，继续桥接（新功能一律进 `src/v4/`）。
- **X04** 不做 NPC 日程模拟与复杂对话树。
- **X05** 不改 `SAVE_KEY` 与 `VER=2`；新字段必须同时进 `newState()` 与 `sanitizeSave` 白名单。

## 三、约束
- 交付物必须仍是双击可玩的单文件 `dist/index.html`（`file://` 可用）。
- 每轮改动都要有：`tsc --noEmit` 干净、vitest 全绿、浏览器探针（playwright 直驱）与 OCR 截图证据。
- 平衡红线：不引入"点一下白拿"的无限资源；不为难度而难度（不搞纯随机致死）。
